# Fuel Consumption Prediction

## Project Overview
This project analyzes vehicle data to understand fuel efficiency and predict fuel consumption efficiency in miles per gallon (MPG) using Python and machine learning.

## Objectives
- Explore and clean vehicle data.
- Analyze relationships between vehicle features and fuel efficiency.
- Train and compare machine learning regression models.
- Evaluate model performance using appropriate metrics.
- Visualize insights using Power BI.

## Tools and Technologies
- Python
- Pandas and NumPy
- Matplotlib and Seaborn
- Scikit-learn
- Google Colab / Jupyter Notebook
- Microsoft Power BI

## Machine Learning Models
The project compares:
- Linear Regression
- Ridge Regression
- Random Forest Regressor
- Gradient Boosting Regressor

Models are evaluated using:
- MAE (Mean Absolute Error)
- RMSE (Root Mean Squared Error)
- R² Score

In my initial model comparison, Random Forest achieved the best results among the tested models. Final scores should be confirmed using the final notebook.

## Dataset
The project uses the Auto MPG dataset, which contains vehicle characteristics such as cylinders, displacement, horsepower, weight, acceleration, model year, origin, and MPG.

## Project Files
- `fuel_consumption_prediction.ipynb` — Python analysis and model training notebook.
- `auto_mpg_cleaned.csv` — cleaned dataset.
- `fuel_prediction_results.csv` — model prediction results.
